METHODOLOGY. Input: 172 candidates; 17 removed as near-duplicates across 13 merge groups, leaving 155 rows (full table above, sorted by fitScore desc). Score = 10 x (0.30*seclusion + 0.25*scenery + 0.15*roadFun + 0.10*julyFit + 0.10*hotelFit + 0.10*(10-crowdRisk)), then multiplied by a drive-time fitness factor: <4h one-way = 0.82+0.03h (a 2.5h run tops out ~0.89 — too short to feel like getting somewhere); 4-6h ramps 0.94->1.00; 6-11h = 1.00 (ideal); 11-12h = mild penalty to 0.94; >12h = heavy penalty (0.94 - 0.15/hr, floor 0.60).

MERGES (kept <- dropped): Cherohala Skyway/Bald River (Maryville terminus, 87.5) <- Cherohala/Joyce Kilmer 2.5h version (identical road, better terminus and drive length); Breaks Interstate Park wildcard (76.8) <- two other Breaks listings; Back of the Dragon + Burkes Garden combo (81.2) <- standalone Back of the Dragon AND standalone Burkes Garden (the combo IS both); Highland Scenic Hwy + Cranberry Glades (89.0) <- WV-150+Green Bank+Cass wildcard, standalone Green Bank, standalone Cass (all same corridor; Green Bank/Cass survive as en-route add-ons in the winner's pitch); Highland County/Monterey 7h version (83.5) <- 6.5h duplicate; Providence Canyon Deep-South listing (69.8) <- FL-region duplicate; Cumberland Gap wildcard (65.5) <- NHP duplicate; Red River Gorge Slade loop (63.5) <- Nada Tunnel wildcard; Jekyll/Driftwood Brunswick listing (49.3) <- second Driftwood listing; Ocracoke 9.8h listing (61.0) <- Cedar Island ferry wildcard; Moonshiner 28 chain (71.8) <- Fontana/Calderwood/Dragon listing (same dams); Suches loop (64.0) <- Helen+Richard Russell wildcard (same roads, Helen adds crowds; Brasstown Bald kept separately as the summit play); Mount Mitchell via NC-80 (65.3) <- NC-226A version.
